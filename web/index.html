CoreS3をPCに接続してください

  1. PCのChrome または Edgeでこのページを開きます。
  2. CoreS3をデータ通信対応のUSBケーブルで接続します。
  3. 下のボタンからCoreS3のポートを選び、INSTALLへ進みます。

このブラウザでは書き込めません。PCのChromeまたはEdgeで開いてください。

HTTPSの書き込みページから開いてください。

ファームウェアを確認しています…

現在のCoreS3のアプリを書き換えます。「Erase device」を選ぶと保存データも消えます。

書き込み後の確認

画面上部に 0.2.0-dual と表示されます。A/Bそれぞれの BP1〜BP3までの距離 とnLosの生値を表示します。

下のセットから2DK-A/Bと固定側2BPも更新してください。まずBP1を1台だけ動かして距離を確認します。対象は両方とも基板Rev.4.1です。

実測距用の試験版です。
ビルドと通信処理のテスト済みですが、2BPとの実機測距はまだ未確認です。

2DK A/B・固定側BP1〜BP3の測距BINをダウンロード

2DK・2BPはこれまでのDK6 Windows GUI「任意のBIN」で書き込みます。ZIP内のRANGING_SETUP.mdに機器別のファイル名を記載しています。

CoreS3 PORT Aの配線

2DK側CoreS3側
AのPIO_13黄色 GPIO2
BのPIO_13白色 GPIO1
A/BのGND黒色 GND

赤色5Vは接続しません。各2DKはUSBで給電します。以前の外付けI²Cプルアップは外してください。

接続できない場合
  • 他のシリアルモニタや、同じポートを開いているタブを閉じてください。
  • CoreS3のRESETを約3秒押し、緑のランプが点灯したら離して、もう一度接続してください。
  • 書き込みモードへの切り替えでポートが変わった場合は、選び直してください。
  • USBケーブルが充電専用ではないことを確認してください。
