  1. PCのChrome または Edgeでこのページを開きます。

  3. 下のボタンからCoreS3のポートを選び、INSTALLへ進みます。

ファームウェアを確認しています…

現在のCoreS3のアプリを書き換えます。「Erase device」を選ぶと保存データも消えます。

書き込み後の確認

画面上部に 0.1.0-dual と表示されます。A/B用の2DK試験版を接続すると、両方に UART TEST が表示され、受信数が増えます。

現在はUART通信の試験版です。
2DKの試験用BINは合成データを送ります。UWBによる実距離の測定は行いません。

2DK A/Bの試験BIN・手順をダウンロード

2DKへの書き込みは、これまでのDK6 Windows GUIを使います。

CoreS3 PORT Aの配線

2DK側CoreS3側
AのPIO_13黄色 GPIO2
BのPIO_13白色 GPIO1
A/BのGND黒色 GND

赤色5Vは接続しません。各2DKはUSBで給電します。以前の外付けI²Cプルアップは外してください。

接続できない場合
  • 他のシリアルモニタや、同じポートを開いているタブを閉じてください。
  • CoreS3のRESETを約3秒押し、緑のランプが点灯したら離して、もう一度接続してください。
  • 書き込みモードへの切り替えでポートが変わった場合は、選び直してください。
  • USBケーブルが充電専用ではないことを確認してください。
