# 0.3.0 / 1111〜7777・A/B同時動作の測距試験版

Type2DK Rev.4.1 ×2とType2BP EVK Rev.4.1 ×1〜7用。
A/Bの同時動作を優先するため固定側も更新します。既存1111〜6666の番号は維持し、追加の2BPは7777です。
旧anchor1_controlee.hexをそのまま使う互換版ではありません。

2DK-A/Bの測距BINと、固定側1111〜7777の7種類のBINを同梱します。
CoreS3も0.3.0-dualへ更新し、最初は7777を1台だけ使ってA/B両列の距離を確認します。
手順はRANGING_SETUP.mdです。

A/Bは別MAC・別session ID・別チャンネル（5/9）。各2DKは1対多の1セッション、各2BPは応答役の2セッション。
設定周期は500 ms。2BPの無線部は共有されるため、実効周期・欠測は実測が必要です。
2DKの両方はPIO13 TX、CoreS3 PORT A黄=A/白=B。加速度センサ取得なし。
画面は1111〜7777の7行とA/B列、USBにはanchor_hex・距離・nLos raw・共通受信時刻を出します。

ARMビルド、ホスト試験、起動ヘッダ/CRC検証済み。**実機UWB測距・7台同時動作は未確認**です。
